# Psyche Build v0.0.1 Multiplatform Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the first public Psyche Build release as `v0.0.1`: signed and notarized macOS DMGs for Apple Silicon and Intel, an internal-only TestFlight build `0.0.1 (1)`, a curated first-release changelog, and a native `opencoven/tap/psyche-build` Homebrew Cask.

**Architecture:** The root package remains the semantic-version authority, and tested release helpers synchronize macOS and generated iOS metadata. One protected GitHub Actions workflow verifies the exact signed tag, tests every product surface, builds both macOS architectures, uploads and validates the internal TestFlight build, and only then publishes the GitHub Release. A separately retryable Homebrew tap workflow consumes the complete public release and opens a generated Cask PR. Repository visibility and credentials remain gated behind a final redacted secret audit and protected GitHub environments.

**Tech Stack:** Node.js 24, pnpm 10, TypeScript, Vitest, Rust 1.95.0, Tauri 2, Swift 6, Xcode 26.2 (`17C52` in CI), XcodeGen 2.45.4, App Store Connect API, GitHub Actions, Apple codesign/notarytool, and Homebrew Cask.
