# psyche Brand Sources

This directory defines the source layout for psyche brand assets used by the documentation site.

- `psyche-wordmark.svg` is the master vector wordmark.
- `psyche-mark.svg` is the compact mark.
- `psyche-hero.svg` is the still composition rendered for public docs.
- `psyche-og.svg` is the social card source.
- `psyche-motion-scene.mjs` is reserved for future motion rendering.
