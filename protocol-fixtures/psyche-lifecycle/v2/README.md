# Independent execution qualification

Install the frozen repository dependencies and run `bash protocol-fixtures/psyche-lifecycle/v2/qualify.sh` from the Build checkout on macOS or Ubuntu. The command enters an empty directory with IP networking disabled, verifies the pinned package, runs its six groups of negative evidence controls, exercises the native adapter and checks the complete transcript. The control with six distinct effect IDs and two reported executions is rejected with `effect_count_mismatch`. A healthy run retains the same ID, approval binding, receipt bytes and count across first delivery, restart and native rollback. Lost acknowledgement remains unknown.

The v2 adapter uses the original native fixture and its exact launch digest. A handler calls the inherited test sink and waits for its committed execution ID. A separate reader checks the persisted request, the original native action, the approval request and the terminal receipt. A denied approval resolution and a cancelled action retain their native outcomes across reopening. Moving to a fresh native epoch can invalidate a pending approval after an operator denial. This migration only affects disposable qualification data.

To exercise the previous reader, run `bash protocol-fixtures/psyche-lifecycle/qualify.sh`. The packaged v1 archive and its immutable pin are retained. The generic contract belongs to Psyche, and this fixture owns the Build-specific evidence. [Experimental owner agreement](https://github.com/OpenCoven/psyche/pull/41#issuecomment-7079261966)
